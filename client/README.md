# TaskSync - Student Task Tracker

TaskSync is a MERN stack task management application developed for internship assignment purposes.

The application allows users to:

- Add tasks
- View tasks
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks
- View analytics dashboard



# Tech Stack

Frontend:
- React
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose



# Features

Add Task  
Edit Task  
Delete Task  
Search Tasks  
Filter Tasks  
Dashboard Analytics  
Responsive UI  
Loading State  
Empty State
